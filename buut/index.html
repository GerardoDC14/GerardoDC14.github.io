Servicios Rust y persistencia reales.

01 / ACCESO

Cuenta individual

Utiliza el acceso recibido por un canal privado. Los permisos se comprueban en el servidor para cada registro.

02 / DATOS

Sólo información ficticia

Esta demostración no admite expedientes, identificaciones o documentos reales. El riesgo y las aprobaciones normativas conservan sus límites provisionales.

03 / DISPONIBILIDAD

Conexión temporal

La aplicación depende de que la laptop permanezca encendida y conectada. La dirección HTTPS del túnel puede cambiar al reiniciar.

La entrada y la aplicación

Esta portada está alojada en GitHub Pages. Abrir demo lleva a la aplicación autenticada en una dirección HTTPS independiente, donde se ejecutan la interfaz y su API. El recorrido incluye persistencia, permisos por registro y recuperación verificada con datos sintéticos.

Para probar archivos desde el celular, descarga estas muestras ficticias y selecciónalas en la ficha del cliente: Muestra 1 (.txt) · Muestra 2 (.txt).
